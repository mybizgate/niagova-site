# Niagova — SEO and AI-visibility audit

Crawled 2026-11-03 · https://niagova.com/ (single-page site) · Shinjiru shared hosting (cPanel, LiteSpeed) · repo `mybizgate/niagova-site`, platform v1.5.2.

**One-line version:** production serves the full site correctly, but the gallery and configurator existed only after JavaScript, the H1 was a slogan without a subject, there was no HTTPS/www canonical redirect, and no `llms.txt`. All code-level fixes are applied locally and verified; the redirect rules are recommended, not deployed.

## Confirmed on production (evidence)

| Check | Result |

## Confirmed in the page (before → after)

1. **JS-only content (high impact).** The demo gallery (12 cards), demo filters, business-type select and need chips were empty elements filled by `script.js`. Crawlers that do not execute JavaScript saw none of the demo names, sectors or links. → Rendered statically in `index.html`; the script now only enhances (it skips rendering when the markup already exists and still handles filtering, the configurator and the calculator). Verified: raw HTML without JS contains 12 `<article class="demo">` and all 12 business options; with JS the dental filter returns 2 cards and the configurator still recommends correctly.
2. **H1 was the slogan alone** ("You name it. We build it."). → "Websites, booking systems and business applications for Malaysian SMEs. You name it. We build it." The slogan is kept as a highlighted second line; hero typography rebalanced so the longer H1 keeps the premium look at 390 px and 1440 px.
3. **Title 75 chars** → "Niagova | Websites & Business Systems for Malaysian SMEs" (55).
4. **Meta description 199 chars** → 147 chars.
5. **Structured data.** Single `ProfessionalService` with empty `sameAs` and no hours. → `@graph` of `ProfessionalService` (name, alternateName MyBizGate, logo, image, email, phone, address from the business card, Malaysia as service area, Mon–Sat 09:00–18:00 as stated on the page, sales contact point, the three published offers), `WebSite`, and `FAQPage` generated from the eight real FAQ entries. No reviews, ratings or founder data were added because none are verified.
6. **Images.** Hero, team and collage were served at 1536 px to every viewport. → `srcset` with 640/960/1536 variants and `sizes`; the mobile viewport now loads the 640 px hero (19 KB vs 74 KB). Preload updated with `imagesrcset`/`imagesizes`. Three decorative mock-up thumbnails had no dimensions → width/height added (alt stays empty: decorative). Demo card images now carry descriptive alt text and dimensions. `decoding="async"` on all photos. Below-the-fold photos stay lazy; the hero stays eager with `fetchpriority="high"`.
7. **Heading hierarchy.** One H1, sections as H2, cards/plans as H3; order checked, no skipped levels. Unchanged.
8. **Internal links.** All sections reachable from the header and footer; 11 external links (WhatsApp, Google Fonts). Unchanged.
9. **Social tags.** Added `og:image:width/height/alt`, `twitter:title`, `twitter:description`, `twitter:image`.
10. **robots.txt.** Kept allow-all; added explicit allow blocks for ClaudeBot, GPTBot, PerplexityBot and Google-Extended so a future blanket rule cannot silently exclude them.
11. **llms.txt** added at the root with verified facts only (services, audience, process, published prices, contact, hours).

## Recommended, not applied

- **Canonical HTTPS + non-www redirect** and caching/security headers: see `docs/htaccess.recommended`. The addon docroot already contains a cPanel-generated PHP block in `.htaccess`; paste the Niagova sections above it via File Manager rather than committing an `.htaccess` to the repo, because the FTP sync would replace the server file and cPanel may rewrite it. Enable HSTS only after confirming every niagova.com host is HTTPS.
- **Google Business Profile, Bing Places and directory listings** with the exact name, address and phone used on the site. Not checked here.
- **mybizgate.com → niagova.com 301** at the domain level (separate docroot) to carry the old brand's signals.
- **Demo links** still point at `*.mybizgate.com` subdomains; move them under niagova.com when the demos migrate.
